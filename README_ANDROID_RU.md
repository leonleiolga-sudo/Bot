# VASIXZZ OSINT BOT V1.3 — без API-ключей

## Что изменилось
- Brave Search API удалён.
- Не нужен API-ключ и регистрация в Brave.
- Поиск публичных результатов выполняется через HTML-выдачу DuckDuckGo.
- Остальная схема: Telegram webhook + Render Web Service.

## Важно
DuckDuckGo может ограничивать автоматические запросы или менять HTML-разметку. Поэтому поиск без API бесплатный, но менее стабильный: иногда результаты не придут. Render Free также может усыплять сервис после периода бездействия; это не гарантирует круглосуточную работу.

## Запуск с Android
1. Создай репозиторий GitHub и загрузи все файлы из ZIP.
2. На Render выбери New → Blueprint и подключи репозиторий.
3. В переменной BOT_TOKEN вставь токен от @BotFather.
4. Запусти Deploy.
5. Открой Telegram и отправь боту /start.
6. Для поиска используй /scan username.

Никому не отправляй BOT_TOKEN. Бот ищет только публично индексируемые страницы и не получает закрытые данные.
